# Changelog

## [1.0.0] - 2026-10-27
### Added
- Product identity, platform-aware directories, receipts directory
- Single-instance lock, CLI flags (--version, --help, --diagnostics, --allow-multiple)
- Rotating log handler, diagnostics bundle export
- Restore from backup UI, emergency backup before restore
- Debian packaging (.deb) with desktop entry, man page, icons
- Windows packaging pipeline (PyInstaller spec, Inno Setup, GitHub Actions)
- Tests moved to tests/, Makefile, CI workflow
- Documentation (README, INSTALL, LICENSE)
- Hardened shutdown/exit to prevent UI freezes
